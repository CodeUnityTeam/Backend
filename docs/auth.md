## Авторизация

### Запросы для получения кода авторизации:

**Google**:

https://accounts.google.com/o/oauth2/v2/auth  
?client_id=  
&redirect_uri=  
&response_type=code  
&scope=openid email profile  
&access_type=offline  
&prompt=consent  

**Yandex**:

https://oauth.yandex.ru/authorize  
?response_type=code  
&client_id=  
&redirect_uri=  
&state=AAA  

**Mai.ru**:

https://connect.mail.ru/oauth/authorize  
?client_id=  
&response_type=code  
&redirect_uri=
