# Проекты (Projects)

Это центральный модуль для работы с проектами на платформе.  
Он объединяет публикацию, отклики, приглашения, лайки, рекомендации и управление участниками.

## Логика взаимодействия
Раздел базируется на взаимодействии **Автор <-> Соискатель**:
1. **Отклик**: Пользователь (`applicant`) -> Проект.
2. **Приглашение**: Автор (`author`) -> Пользователь.

### Статусная модель
- **Проект**: `draft` (черновик), `published` (активен), `recruiting_closed` (набор закрыт), `archived` (архив), `blocked` (заблокирован).
- **Отклик/Инвайт**: `pending` (ожидание), `approved` (принят), `rejected` (отказ), `withdrawn` (отозван).
- **Участник**: `author` (владелец), `member` (участник).

> **Результат**: При переходе отклика в статус `approved`, пользователь автоматически становится участником (`member`) проекта.

## Структура данных
- **Project**: Основная информация (тайтл, описание, локация, даты) и связи (Skills, Specializations, WorkFormats).
- **ProjectParticipant**: Список подтвержденных участников проекта.
- **ProjectLike**: Toggle-лайки (лайкнул/убрал).
- **Response**: Единая модель для хранения откликов и приглашений.
- **WorkFormat**: Справочник типов занятости (Удаленно, Офис и т.д.).

## API эндпоинты

| Метод | Путь | Описание |
| :--- | :--- | :--- |
| `GET` | `/projects/` | Список проектов (фильтры, поиск, пагинация) |
| `POST` | `/projects/` | Создание нового проекта |
| `GET` | `/projects/{id}/` | Детальная информация |
| `PATCH`| `/projects/{id}/` | Редактирование |
| `DELETE`| `/projects/{id}/` | Архивация проекта (soft delete) |
| `POST` | `/projects/{id}/like/` | Поставить/снять лайк |
| `GET` | `/projects/recommendations/` | Подбор по навыкам пользователя |
| `POST` | `/projects/{id}/responses/` | Откликнуться на проект |
| `POST` | `/projects/{id}/invite/{user_id}/` | Пригласить пользователя |
| `GET` | `/projects/responses/` | Лента откликов и приглашений |
| `PATCH`| `/projects/responses/{id}/status/` | Изменить статус (approved/rejected/etc) |
