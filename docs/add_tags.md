## Добавление навыков, специализаций, форматов работы в БД.

Необходимо иметь запущенный проект, запущенную базу данных и применённые миграции.
База данных должна быть чиста (для моделей Skill, WorkFormat, Specialization), для избежания ошибок при загрузке данных.

Для добавления используем команду:
```bash
python manage.py loaddata fixtures/tags/*
```
Команда загрузит навыки, спициализации и форматы работы в базу данных с предустановленными первичными ключами (uuid).


## Добавление тестовых данных в проект.
Перед добавлением убедитесь что БД запущена, проект запущен, применены миграции и добавлены теги в БД из каталога ```fixtures/tags/```

Для добавления тестовых данных в проект имеются два скрипта ```create_users.sh``` и ```create_obj.sh```, они отправляют curl-запросы на эндпоинты с данными из соответсвующих json-файлов.

**Для регистрации пользователей в проекте, запущенном локально, и подтверждения email используем команду**
```bash
bash fixtures/test_data/create_users.sh
```
**Для добавления данных в проект, запущенный локально, используем команду**
```bash
bash fixtures/test_data/create_obj.sh
```

**На сервере используется [`load_on_dev.sh`](../fixtures/test_data/load_on_dev.sh), который сам подставляет нужные переменные:**
```bash
sudo docker compose -f docker-compose.dev.yaml exec backend bash fixtures/test_data/load_on_dev.sh
```

Что делает скрипт:
* Получает токены
* Обновляется профиль автора - меняем статус, информацию, скиллы; загружается аватар для автора.
* Создаются проекты с данными из projects.json
* Создаются вопросы с данными из questions.json
* Создаются ответы с данными из answers.json на вопросы.
* Делаются отклики на созданные проекты, приглашаются пользователи на созданные проекты (отклик от автора)
* Ставятся лайки на проекты, вопросы.

> **Важно:** Повторный запуск скрипта создаёт новые объекты при отсутствии валидации данных в проектах, вопросах, ответах.
