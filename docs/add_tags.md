## Добавление навыков, специализаций, форматов работы в БД.

Необходимо иметь запущенный проект, запущенную базу данных и применённые миграции.
База данных должна быть чиста (для моделей Skill, WorkFormat, Specialization), для избежания ошибок при загрузке данных.

Для добавления используем команду:
```bash
python manage.py loaddata fixtures/*
```
Команда загрузит навыки, спициализации и форматы работы в базу данных с предустановленными первичными ключами (uuid).
