# Admin-панель проекта

## Доступ
- **URL:** '/admin/'
- **Суперпользователь:** Создается командой `python manage.py createsuperuser`

## Особенности админ-панели
- Права доступа к моделям в админке определяются миксином `'RolePermissionsMixin'` из `'.core/admin_mixins.py'`.
- Все новые модели необходимо регистрировать с наследованием указанного миксина.
- Поля `'is_stuff'`, `'is_superuser'` - только для чтения, их значение меняется при назначении роли пользователя.
- Модератор имеет ограниченный функционал - может просматривать все модели, редактировавать или удалять сущности только в моделях **Projects** и **QnA**. Добавлять никакие сущности не может.
- Администратор имеет права суперпользователя.
