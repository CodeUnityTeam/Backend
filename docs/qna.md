# Вопросы и ответы (Q&A)

Раздел системы для обмена знаниями, который включает создание вопросов, обсуждение в ответах и систему реакций.

### Основные сущности
- **Вопросы**: Могут быть анонимными, поддерживают привязку технических навыков (Skills).
- **Ответы**: Поддерживают иерархическую структуру (ответ на ответ) и статус активности.
- **Лайки**: Реализованы для вопросов и ответов с toggle-логикой (поставить/снять).

### Работа с медиа
Вопросы и ответы поддерживают прикрепление изображений. 
Подробное описание процесса загрузки и хранения файлов вынесено в раздел [S3 Minio](s3_minio.md).

### Администрирование
В админ-панели реализован кастомный интерфейс для управления изображениями:
- Загрузка файлов напрямую в MinIO.
- Автоматический сбор метаданных файла.
- Превью изображений в списках и формах редактирования.
